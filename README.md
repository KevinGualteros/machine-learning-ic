# Clasificación de imágenes mamarias

Proyecto académico de clasificación aplicado a imágenes relacionadas con el
cáncer de mama. El material aborda el análisis de datos, el modelado y la
evaluación del comportamiento del clasificador.

## Archivos incluidos

- `Documentación.pdf`: documentación del proyecto.
- `Presentación.pdf`: resumen para exposición.
- `Proyectoentrega1.m.txt`: script de preparación y procesamiento de datos.
- `CAD_Mamario_ResNet18.m.txt`: script de la aplicación de clasificación.

Los scripts se encuentran guardados como archivos de texto (`.m.txt`), no como
archivos MATLAB ejecutables (`.m`). Revisa su contenido y guárdalos con la
extensión adecuada antes de intentar ejecutarlos.

## Datos y ejecución

El código hace referencia al conjunto CBIS-DDSM y a archivos de datos y modelos
MATLAB que no están incluidos en este repositorio. También contiene una ruta
local de Windows definida en el código; debe ajustarse al equipo y a la
ubicación de los datos antes de ejecutar los scripts.

Por lo tanto, los archivos permiten consultar el trabajo, pero no constituyen
por sí solos un entorno reproducible. Se requiere MATLAB y acceso independiente
a los datos y artefactos que esperan los scripts. Consulta primero la
documentación y la presentación para conocer el alcance y los resultados.
